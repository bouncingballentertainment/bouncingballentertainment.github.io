YouClipping Privacy Policy

Last updated: 2026-11-19

What the app does

YouClipping is a personal tool operated by Bouncing Ball Entertainment. It uploads edited video clips to the operator's own YouTube channel, Instagram account and TikTok account, and reads the performance statistics of those clips.

Google user data we access

  • youtube.upload: to upload and schedule clips on the channel owner's channel.
  • youtube.readonly: to read the channel's video list and upload status.
  • yt-analytics.readonly: to read views and retention statistics of the owner's own clips.

TikTok user data we access

  • user.info.basic: to read the connected account's display name and username, only to show which account is connected.
  • video.publish: to post clips to the owner's own TikTok account, with the caption, privacy and interaction settings the owner chooses.

We do not read followers, messages or any other data from the TikTok account.

Instagram user data we access

The Instagram API with Instagram Login is used only to publish clips as Reels to the owner's own Instagram account and to read that account's username.

How the data is used and stored

This data is used only to upload clips and to measure how they perform, so the tool can improve its clip selection. Sign-in tokens and statistics are stored locally on the operator's own computer. They are not sold, shared with third parties, or used for advertising.

YouTube API Services

YouClipping uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Revoking access

You can revoke this app's access at any time: Google at myaccount.google.com/permissions, TikTok in the TikTok app (Settings and privacy, Security, Manage app permissions), Instagram in Settings, Website permissions, Apps and websites. When access is revoked, the stored tokens are deleted.
